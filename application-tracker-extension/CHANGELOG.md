# 更新记录

## 0.5.0 — 开发中

### 2026-10-13：侧栏简化、资料配对与投递记录草稿

- 侧栏改为「识别本页 → 核对预览 → 填写」，默认展开「要你看」，其余按可填、网页处理、选填和网页已有分组收起；超过 15 道需核对题先显示前 15 道，支持展开全部。题目来源按需展开，经历绑定保留，填写结果移到顶部，失败直接显示、成功默认收起。
- 「更新」保留仍适用的人工修改与取消选择；「重新识别」重新准备。语言先按页面判断，手动选择后优先沿用；失效计划须重新识别，同页已完成结果保留。侧栏会话结构升为 7，旧会话需要重新识别；manifest 与 package 版本仍为 0.4.0。
- 常规 AI 流程改为题目与资料目录配对，只发送编号、名称、类型、所属对象和适用记忆的问题，不发送资料内容、记忆答案、岗位背景、完整网址或网页已有答案。结果在本地取值、格式化和校验，不让 AI 生成直接事实。
- 长文本不再自动生成草稿。自我介绍、申请动机与已确定经历描述使用单题「AI 写草稿」，先展示这一题、岗位说明和相关资料的发送范围，用户确认后才请求；取消不发送，失败或内容变化保留原答案。事实型 textarea 不开放生成。
- 新入口保护已明确的题意与敏感标记，拒绝未确定经历的资料/记忆复用；记忆别名仅按明确的同题规则复用。日期拆分先校验完整来源，保留已确认的精度；选项仍要求本地唯一匹配。
- 修复原生 label 包裹 select 时把选项文字混进题目；保留嵌套题目文字与 radio/checkbox 选项文字。
- 识别页面时准备投递记录草稿，填写后供用户核对并手动记录；只补未编辑的空项，主动清空不被异步识别覆盖。最近岗位需显式选择，重复记录先提示，仍然记录的确认绑定当时的草稿与重复项；保存成功后不再出现保存按钮。
- 保留确认前不写网页、只填空字段、条款与人工编辑保护、失败残留安全撤销、后台串行持久化及不自动提交。个人资料与备份格式不变，原改进方案的资料 v2、整页理解未推进。
- 有意迁移旧验收：删除「只看需处理」筛选和单条记忆保存入口，对应界面测试改验五组展开/折叠和批量保存；AI 题意识别与自动生成的旧测试改验目录配对及显式单题草稿，保留来源、主体、语言、选项、日期、取消、失败和人工改动保护。原生 option 同义词不再需要自动 AI 改写，保留本地映射验收。
- 新增分组与语言、资料目录隐私、配对校验、单题发送确认、记录草稿与重复保存回归；最终 534 项检查通过，另有三份清理网页样本达标。本轮结果见 [执行记录](docs/2026-10-13-simplify-execution.md)，不沿用前一轮通过数量。实施范围见 [简化方案](docs/2026-10-13-simplify-plan.md)。

### 2026-10-13：阶段 2 审查修复

- 修复 fieldset/legend 和 ARIA 题名的边界，保护隐私条款与授权选项；明确调剂等业务问句可继续预览，签名/同意声明仍手动处理。
- 真实用户点击选项内部文字可停止操作；菜单关闭期间再次检查人工编辑和网站覆写，不误报已核验或认领外部值。
- Ant Design 3 范围日期通过公开输入与右侧日历操作提交；逐次核对年月、禁选与唯一日期，移除按日号任取第一个候选的兜底。日期格式仅提取 token，页面和资料规划共用一致的自包含解析逻辑。
- 延长关闭动画的检查窗口；最终补救成功会保留已读取选项。无关联菜单仅认领本次新出现的唯一菜单，忽略常驻列表。
- 失败但确有助手残留改动可安全撤销；保护后来修改，支持跨批次及中断恢复，不把失败结果保存为成功记忆。
- 同 form 多标题分区与上下文证据一起修正；重复经历要求相同题目集合，避免将两列题目行拆成多个经历。未适配只读下拉给出手动选择提示。
- 有限支持同学历标签“及以上”选项；不凭本科事实添加统招/全日制条件。保留精确优先、唯一候选和否定词边界。
- 文字投递来源可保存、备份和恢复；界面只将 HTTP/HTTPS 地址作为链接。Excel 以可见表为准，新增隐藏记录 ID，维护历史一致性；覆盖前通过后台队列原子保存完整恢复点并检查并发修改。
- 将选择组、日期格式、上下文回归加入浏览器验收。空 div 的下拉测试增加实际可见高度，保留业务 visible() 规则。详细结果见 [修复记录](../docs/2026-10-13-claude-fixes.md)。

- 阶段 0：接入真实页面基线测试；确认活动入口无引用后移除 10 个废弃模块和对应测试，保留 aiSuggest。
- 阶段 1：统一收集结构化招聘数据、页面标签、标题与站点信号；提供来源标签、最近岗位和可选 AI 兜底；移除常驻 content scripts。
- 有意调整的旧验收：真实扩展的草稿隔离/清空测试原先期待公司为空，现期待标题识别出的“示例公司”；草稿清空恢复网页预填，符合通用岗位抓取行为。
- Moka 原专用提取器测试迁移到通用提取器的站点候选和标题规则，保留五项原行为断言；旧模块已删除。
- 阶段 2：按结构识别题目、分区和重复段；新增日期、级联、Element 下拉与无原生输入框的选择组适配；统一选项同义词及日期格式校验。
- 内嵌表单读取失败时显示对应域名的授权按钮，用户点击后只申请该域名权限；仅明确登录页限制填写，其他页面允许预览并提示核对。
- 增加本地 Ant Design 3/5、Element UI 2 组件页，校验框架内部值、显示值和撤销结果；没有清空入口的受控单选组明确提示手动撤销。
- 测试入口改为明确匹配 `test/*.test.js`，避免将组件页面脚本作为 Node 单元测试执行；并未删减实际测试。

## 0.4.0 — 2026-09-26

加入可选截图辅助识别，保留「识别并预览 → 一次确认填写」流程。

- 在 AI 设置中单独启用截图辅助；文字题意不明确时自动分析当前申请页可见区域，没有新增逐题确认步骤。
- 截图遮盖输入控件和内嵌页面，标记可对应的空白字段。视觉结果辅助判断题目及教育分区，答案仍来自个人资料或经过校验的原有建议流程。
- 视觉结果不覆盖明确题意、人工修改或手动绑定的经历；预览标注截图依据并提示重点核对。
- 同题更新预览保留视觉题目的人工修改和经历绑定；只确认部分教育字段时，剩余模糊字段等待指定，避免本科院校与硕士专业混用。
- 捕获前后检查活动标签、文档、滚动和布局变化。无权限、图片请求失败或页面变化时回退文字识别，不截取其他活动页面来代替目标页。
- 原图和处理后的截图不写入本地存储、会话或备份；其他可见文字或图片仍可能含个人信息，设置中明确发送范围。
- 未增加浏览器权限；不支持任意坐标点击、纯画布表单、截图识别内嵌页面或自动提交。真实网站和真实 AI 的识图准确率尚未现场验收。
- 本轮 201 项逻辑、32 项浏览器控件、21 项助手界面、12 项真实扩展、7 项截图检查最终通过，共 273 项。验证边界及一次并行核验超时见 [截图辅助验证记录](../docs/2026-09-26-visual-recognition.md)。

## 0.3.1 — 2026-09-22

按用户选择简化为“识别并预览 → 一次确认填写”，保持确认前不写入网页。

- 有效答案默认选中，包括 AI 草稿、长文和已确认记忆；需核对的答案突出标记，缺资料或校验失败的项目不选。
- 补充答案后自动加入本次填写，支持全选、取消全选和“只看需处理”。同题刷新保留明确取消，切换语言不沿用旧选择。

- 已识别的经历对应信息收起显示，需要调整时再展开。
- 增加本次答案批量保存入口，学习预览默认全选，一次确认保存；同题多次填写使用最近一次成功答案。
- 169 项逻辑、14 项助手界面、10 项真实扩展验证通过。详见 [验证记录](../docs/2026-09-22-preview-confirmation.md)。

## 0.3.0 — 2026-09-22

本轮围绕填写准确性、网页变化后的处理和本地数据可靠性修正。源码版本已统一为 0.3.0，刷新 Chrome 扩展后生效。

### 申请助手

- 在准备阶段读取受支持下拉框的真实选项，支持明确资料驱动的搜索候选读取；选项失败或变化时提示重新核对。
- 综合完整题目、分区、帮助文字和约束判断题意，区分学校名称/所在地、专业/排名、学位/成绩等容易混淆的问题；AI 可复核不确定的本地判断。
- 保留稳定目标和文档检查，写入前核对控件状态，写入后等待回读；动态字段、条件题和级联选项变化后更新预览。
- 增加“更新问题，保留草稿”、分组折叠和必填缺口导航；新问题、已变化字段及资料更新后的计划重新确认。
- 完善停止、会话恢复和撤销流程，保护用户原有内容和之后的手动修改。
- 切换语言时清除原语言草稿；取消操作在异步等待后仍然生效，过期的页面检测不会污染新会话。

### 资料与记忆

- 个人资料直接用于本地匹配，移除需要额外“生成 AI 信息库”的日常入口。
- 长期答案须单独确认保存；岗位范围保留查询参数和路由中的岗位标识，移除常见凭据与跟踪参数。
- 旧版范围不完整的问答保留待确认；修改主体和范围使用中文选项，保留已有主体。
- 资料和问答变化后使旧填写计划失效，避免继续使用已过时答案。
- 保存答案对应到具体那次填写，保留原语言与岗位；批量保存固定整批内容，防止切换预览造成答案错配。

### 投递记录与数据保护

- 弹窗按岗位暂存未保存草稿，并提供清空入口。
- 表格、看板同步存储变化；状态修改只更新状态，不再回写整条旧记录。
- 持久数据修改统一进入后台串行队列，增加编辑冲突检查，覆盖多页同时写入和已删除记忆的场景。
- 日期按本机日期生成，修正上海时间凌晨被 UTC 切片算成前一天的问题。

### 完整备份

- 增加完整 JSON 导出、格式校验、数量预览、合并/替换和导入前恢复点。
- 备份包含记录、资料和问答，排除 API Key、设置及临时会话。
- 合并保留相同 ID 的本机数据和已有整份资料；资料不同的新问答待确认。
- 兼容旧版资料 JSON；旧资料备份不覆盖投递记录。Excel 仍只备份投递记录。

### 验证与说明

- 增补逻辑回归、虚构表单、界面及隔离 Chrome 真实 MV3 扩展测试，包括并发保存、恢复往返和表格/看板同步。
- 更新 README、申请资料说明、发布清单及项目记忆，明确 AI 可选调用与发送范围。
- 223 项逻辑、浏览器、界面与真实扩展回归通过，详见 [验证记录](../docs/2026-09-22-reliability-verification.md)。真实招聘网站和真实 AI 服务仍未现场验收。
