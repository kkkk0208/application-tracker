# 发布检查清单

适用于当前申请助手版本。以下方框是发布和现场验收时逐项填写的清单，未勾选不表示代码中没有相应功能。历史 MVP 的“不联网、不填表”已不适用于当前实现。

目前已在隔离 Chrome 和虚构申请表中执行自动化验证；真实招聘网站及真实 AI 服务的现场验收仍待进行。最终测试结果、浏览器版本与计数以本次发布记录为准。

## 安装与权限

- [ ] `manifest.json` 与 `package.json` 版本一致，发布包包含当前源码和 `vendor/xlsx.full.min.js`。
- [ ] 在 Chrome 120 或更新版本加载解压目录，后台服务工作线程无启动错误。
- [ ] 更新后在 `chrome://extensions/` 刷新 Application Tracker，并重新打开弹窗、侧栏及管理页。
- [ ] 已核对 `storage`、`activeTab`、`scripting`、`tabs`、`sidePanel`、`webNavigation` 权限的用途。
- [ ] 已核对固定网站权限：CTgoodjobs、JobsDB、Moka、`job.swsmu.com`、`api.openai.com`；没有误加 `<all_urls>`。
- [ ] 弹窗的「查看全部」「编辑个人信息」「记忆库」「AI 设置」「打开申请助手」入口正常。

## 投递记录和数据一致性

- [ ] 当前招聘页链接、标题、来源及本机当天日期正确，上海时间凌晨不会落到前一天。
- [ ] CTgoodjobs、JobsDB、Moka 的公司、岗位和地点提取失败时允许手动修改；真实站点另行验收。
- [ ] 弹窗关闭后回到同一岗位能恢复草稿，不同岗位的编号或路由不会串用；保存与「清空草稿」会移除草稿。
- [ ] 新增记录、重复提示、搜索、筛选、排序、编辑、删除和批量操作正常。
- [ ] 表格修改备注后，在同时打开的看板改状态，备注保留且两页同步。
- [ ] 两个扩展页面同时新增或修改数据，后台串行保存，不丢记录；状态时间线正确。
- [ ] 编辑窗口所改字段已被另一页面修改时提示冲突，不静默覆盖。

## 申请助手

- [ ] 侧栏绑定原目标标签页；切换标签只提示，点击「改为当前页面」才改绑。
- [ ] 主页面和可访问内嵌页面合并识别；无权限、超时或未检查区域有覆盖提示。
- [ ] 页面刷新、跳转、控件更换、资料或记忆变化使旧计划失效，不把旧确认用于新字段。
- [ ] 标签、分区、帮助文字、必填条件、字数约束和主体用于理解题目；学校所在地、专业排名等不误当学校或专业名称。
- [ ] 原生选项和受支持的自定义下拉使用网页实际选项；搜索下拉读取后恢复原状态，不把相似文字当成唯一正确选项。
- [ ] 日期、单选、多选和重复教育/实习组的预览对应正确，可调整经历绑定和定位原题。
- [ ] 有效答案默认选中，含 AI 草稿和已确认记忆；需核对项突出标记，统一确认前网页不写入答案。
- [ ] 补充有效答案自动选中，全选、取消全选及“只看需处理”有效；同题刷新保留明确取消。
- [ ] 密码、验证码、文件上传、声明、签名和最终提交由用户操作。
- [ ] 写入后等待回读和页面校验，失败或被网页回滚时不显示成功；已有内容不覆盖。
- [ ] 条件题或级联选项改变后停止旧批次并更新预览，新问题需要重新选择。
- [ ] 「更新预览，保留修改」、分组折叠及「查看必填缺口」工作正常；新题需新的统一确认才执行。
- [ ] 「停止」停止后续操作；「撤销本次填写」不覆盖用户后来修改过的值。
- [ ] 关闭再打开侧栏可恢复本次会话，浏览器或扩展重载后要求重新识别。

## 资料和问答

- [ ] 中英文资料、共用联系方式和同一批实习经历编辑正常。
- [ ] 保存资料后助手直接读取，无需手动生成 AI 信息库。
- [ ] 填写成功只记本次结果；批量保存最近的有效答案，学习预览默认勾选，统一确认后才进入长期记忆。
- [ ] 学习网页已有答案时展示核对预览；声明、验证码等不进入学习。
- [ ] 记忆区分主体、语言和岗位范围；岗位编号和路由保留，凭据与跟踪参数移除。
- [ ] 旧版范围不完整的问答保持待确认；中文主体选项保留已有自定义主体。
- [ ] 多页同时保存或删除问答不丢数据，删除的答案不会被旧编辑窗口复活。

## AI 可选调用

- [ ] AI 默认关闭；关闭时所有准备、更新操作均无 AI 请求。
- [ ] 开启时仅在准备或更新问题时按需调用，并显示发送范围。
- [ ] 截图辅助单独默认关闭，已有 AI 设置不会自动开启；保存开关并重开设置页可保持状态。
- [ ] 截图只用于绑定的当前活动申请页；切换标签、文档、滚动或布局变化会使截图失效，缺少权限时提示并保留文字预览。
- [ ] 输入控件与内嵌页面先遮盖再发送；提示其他可见内容仍可能含个人信息，原图和处理后的截图均不持久化。
- [ ] 视觉观察只映射已有字段，拒绝未知编号、低置信度、冲突主体和受保护问题；保持人工编辑及经历绑定。
- [ ] 截图辅助答案标出待核对，统一确认前不写入；模型不支持图片或请求失败仍可完成普通文字预览。
- [ ] 题意理解阶段不发送个人资料值；答案建议仅取相关资料、题目和岗位背景。
- [ ] API Key 仅用于请求鉴权，不出现在提示词、日志、JSON 备份或恢复点中。
- [ ] AI 返回未知字段、错误来源、虚构选项、无法解析的内容时拒绝接受，保留本地结果。
- [ ] 网络错误、超时、限流、取消后给出可理解提示，未完成批次不伪装成成功。
- [ ] 真实 API 模型可用性、服务响应和最终建议质量已单独现场验证，并记录日期；不能仅凭模拟响应验收。

## 完整 JSON 备份与恢复

- [ ] 导出含记录、个人资料、当前问答、旧问答及原始历史备份，不含 API Key、设置或临时会话。
- [ ] 文件损坏、未知版本、重复 ID、错误数据类型等在预览阶段被拒绝。
- [ ] 合并预览显示数量和冲突规则：同 ID 保留当前内容，有本机资料时整份保留。
- [ ] 资料不同的合并场景中，新问答待确认，避免经历对应错误。
- [ ] 替换预览明确替换范围；旧版仅资料/问答备份不删除投递记录。
- [ ] 确认后才写入，导入前恢复点与数据一并保存，可再次预览恢复。
- [ ] 预览后另一页面有更新时，要求重新预览；容量不足或写入失败时原数据保留。
- [ ] 在全新隔离环境完成导出、导入、合并、替换、恢复点的往返测试。
