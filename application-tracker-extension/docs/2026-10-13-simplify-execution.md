## 已完成与必要调整

- 克隆 label 后删除控件再取文字，避免下拉选项污染题目；保留嵌套题目文字和 radio label 行为。
- 五组紧凑预览，默认展开需处理项；保留所有题目 DOM，通过 hidden 折叠。已准备答案默认选中，并保留整批填写确认。
- 填写结果置顶：未完成与撤销结果展开，成功结果折叠；失败可安全撤销的残留仍保留，成功记忆仅通过批量确认保存。
- 当全部可填项都需核对而没有 ready 组时，全选工具放在 attention 标题，避免丢失操作入口。
- 显式语言选择独立暂存为 languageChoice，旧计划的 language 保留来源语义；切换语言不继承原语言草稿。
- stale 状态的识别按钮保留同一文档的填写结果；更换语言仍舍弃旧语言草稿。
- UI 测试使用正常用户点击进入菜单、展开分组/绑定和选择 stale 后的主按钮，未使用 force 绕过可见性。
- 修复测试适配器导航后复用文档编号的问题：documentId 跟随实际 frame token，旧文档路由拒绝；独立视觉回退测试使用新文档，保持原隐私和安全断言。
- 配对请求只含候选题目和本地目录元数据，目录不读取 value/answer；可靠本地答案不重复请求 AI。模型只能返回已有资料编号、有限的姓名/日期转换或 none，取值、唯一选项匹配和格式校验留在本地。
- 拒绝未确定经历、主体/语言不符、薪资题意混用、无效日期拆分与越权事实配对。保留敏感标记；none 会清除不可靠猜测，但不会覆盖“截图仅确认……”的分组安全原因。
- 自我介绍、申请动机和已绑定经历描述可单题请求草稿；事实型 textarea 不开放。发送前显示相关资料名称，确认仅存内存；取消零请求，接口失败保留原答案，网页/资料/记忆/设置变化或批次内容变化撤销确认，返回晚的结果也不能覆盖新状态。
- 原 8 项题意识别测试迁移到配对/草稿测试并保留保护断言。UI 将同义学历本地匹配与真实选项校验保留，不再强制它额外调用 AI；确认卡等待异步校验完成。新增确认期间实际文档导航的 stale 保护和 25 题完整折叠检查。
- 投递记录卡放在顶部填写结果中，识别公司/岗位在后台并行进行，失败不阻塞填写预览。只补未编辑空项，主动清空也有编辑标记；最近岗位只作显式选择，按当前链接生成草稿。
