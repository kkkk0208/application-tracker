# 个人信息与申请信息

当前申请辅助入口是浏览器侧栏「申请助手」。日常操作为「识别并预览 → 确认并填写」，无需逐题勾选；填写成功不会自动学习为长期答案。

## 维护个人资料

在扩展弹窗的「申请信息」或侧栏的「个人信息」进入编辑页。保存后助手直接使用个人资料，无需另行生成 AI 信息库。

可维护的内容包括：

- 中文姓名、英文全名、英文名、电话、邮箱、LinkedIn、GitHub、个人网站。
- 本科及硕士的中英文学校、学历、专业、入学和毕业时间。
- 中英文实习公司、岗位、时间和经历。两个语言页编辑同一批实习，新增或删除同步。
- 签证赞助、工作资格、期望薪资、最早到岗、所在地、搬迁意愿、语言能力、岗位动机、公司动机和自我介绍等常见答案。

资料没有提供的事实应留空。日期尽量按页面要求提供已有精度；只有年月时，不应补造具体日期。公司动机、地区工作资格和薪资口径可能因岗位不同而变化，使用时需结合当前题目核对。

保存个人资料后，已经准备好的侧栏计划会要求更新。修改资料后记得保存；普通资料编辑不会自动保存成长期数据。

## 复制申请信息

弹窗「申请信息」有「中文申请」与「English Application」切换；表格页也保留「申请信息」入口。每个字段或经历部分旁有单独的「复制」，用于无法自动填写的页面。

## 准备、核对、填写

1. 在真实申请表页面打开侧栏，确认顶部显示的目标页面和申请语言。
2. 点击「识别并预览」。助手检查可访问的主页面与内嵌区域，并报告覆盖情况。
3. 读取受支持控件的真实选项，再进行本地匹配。已启用 AI 时，会复核疑难题并准备有资料依据的草稿。
4. 有效答案默认选中，草稿或需要核对的答案会标出；可切换「只看需处理」，按需修改答案、取消不需要的项目或调整经历对应。
5. 点击一次「确认并填写 N 项」，统一确认本次选中的答案。
6. 在结果区和网站核对，最终保存和提交仍由用户操作。

学校、专业、机构等搜索下拉可能需要先打开，再输入本地已有名称读取候选项。助手只使用页面实际提供的选项；不能安全读取或无法唯一匹配时，会留下说明，不凭空创建选项。

已有有效答案的普通事实、AI 草稿和记忆均默认选中，但统一确认前不写入网页。长文、资格和薪资等内容需重点核对；缺答案、校验失败或无法读取选项的项目不会选中。名称相近不等于题意相同，例如“学校所在地”不能用学校名称回答。

教育与实习按页面分组匹配，可在分组处调整对应经历。只有一组没有明确级别的通用教育字段时，当前默认尝试硕士资料；仍应核对侧栏展示的来源。页面明确标注本科或硕士时按标注匹配。

截图只确认同组部分题目的学历时，其他没有明确层级的题目会留待指定，避免本科院校与硕士专业混用。可以补充答案或调整该组对应经历；同题更新预览会保留视觉题目上的人工修改和明确绑定。

## 页面变化、停止与撤销

切换浏览器标签不会改变助手的目标页。需要换一份申请时，在新页面点击「改为当前页面」。页面跳转或刷新后必须重新识别。

网页新增经历、出现条件题或下拉选项变化时，旧批次会停止并更新预览。也可使用「更新预览，保留修改」，在同题同资料时保留编辑和明确取消的选择。新的有效答案默认加入预览，再次统一确认后才填写。「查看必填缺口」用于快速定位尚未完成的必填内容。

「停止」停止后续操作，已经写入的内容保留。「撤销本次填写」尝试恢复助手写入前的值，但不覆盖用户后来修改的字段，也不能撤销网站已经保存或提交到服务器的申请。

## 确认和复用问答

个人资料、可复用问答、本次填写结果分别保存。成功填写只产生本次结果，不自动变成已确认的个人事实或长期模板。

保存答案可使用以下入口，预览默认选中可用答案，仍需确认才保存：

- 填写结果中的「批量保存本次答案」，同题多次填写取最近一次成功结果；也可单独选择「核对并保存为记忆」。
- 「学习网页已填写的答案 → 读取已填写答案」。

默认范围是当前岗位链接。只有允许在不同公司和岗位复用的答案才选择「通用答案」。限定链接保留岗位编号、查询条件和路由，移除常见凭据及跟踪参数。旧版丢失岗位标识或缺少范围版本的答案仍可查看，但需要重新确认后才在限定范围内复用。

「问答记忆」页可搜索、修改问题与答案、选择中文/英文、选择“本人/本科/硕士/实习/家庭成员”等主体，并调整范围。已有自定义主体会保留供选择。来自不同主体、语言或岗位的答案不能因文字相似就当成同一事实。

如果另一个页面修改了同一条问答，当前编辑内容会保留；保存时检查冲突，避免旧窗口把新答案覆盖。删除的答案也不会被旧窗口直接重新保存回来。

## AI 设置与发送范围

AI 默认关闭。开启需要在「AI 设置」保存 API Key、模型和开关。此后在准备或更新问题时按需调用，不需要为每一批再次点击独立的 AI 按钮。

需要识别图片中的题目或不明确的教育分区时，可在同一设置页启用「截图辅助识别」，模型须支持图片输入。回到申请页，点击扩展图标打开助手，保持该页为当前标签，再按平时方式「识别并预览」。预览会标注截图辅助的题目，查看后仍只需一次确认填写。截图仅覆盖当前可见区域；可滚动到其他疑难题后更新预览。

文字题意理解阶段发送问题、分区、提示、约束、真实选项和资料类别；答案建议阶段只选取相关资料片段、页面标题和岗位背景。相关片段可能包含姓名、联系方式、教育或工作经历。文字请求不附带网页已填答案，API Key 不进入提示词，但会随请求鉴权头发送给 OpenAI。侧栏显示本次 AI 发送范围。

截图辅助单独默认关闭。启用后按需发送遮盖后的可见区域截图及字段编号；输入控件和内嵌页面先遮盖，其他文字或图片仍可能含个人信息。截图不存入本地记录、会话或备份。视觉识别只补充可对应控件的题目和分区，不从截图创建个人资料，也不覆盖人工修改或手动指定的经历。无截图权限、页面变化或图片调用失败时继续使用文字识别。

关闭 AI 仍可使用本地匹配、复制、手动补充和填写。网络、服务响应或输出校验失败时保留本地结果。当前已测试模拟响应的协议和校验路径，尚未验证真实 AI 服务的模型可用性或实际建议质量。

## 备份和恢复

个人信息页的「备份与恢复资料」进入记忆页：

1. 「导出完整备份」下载包含记录、资料和问答的 JSON，不包含 API Key、AI 设置或临时会话。
2. 「导入 JSON 备份」先校验和预览，再选择合并或替换。
3. 合并保留同 ID 的本机数据；已有资料整份保留。备份资料不同的新问答会待确认。
4. 替换会按预览恢复完整数据；旧版资料备份不覆盖投递记录。
5. 恢复前保留一个本机恢复点，可再次预览恢复；长期保存仍应下载 JSON。

表格页的 Excel 只包含投递记录，不能恢复个人资料或问答。换电脑后还需重新配置 AI 设置。

## 当前边界

助手不自动翻页、提交申请、上传文件或新增网站的经历块。密码、验证码、同意声明及签名由用户处理。只读、已有内容、隐藏或不支持的字段不会进入通常的批量填写。

截图辅助不执行任意坐标点击；仅支持当前视口主页面内已有可识别表单控件的题目。纯画布表单及截图中遮盖的内嵌页面不在视觉识别范围内，真实模型的识图准确率仍需实际验证。

已在隔离 Chrome 的虚构表单中验证界面和填写流程；尚未现场验证真实招聘网站。对不可访问内嵌区域、关闭的 Shadow DOM 或不适配的自定义控件，请使用定位与资料复制辅助完成。
