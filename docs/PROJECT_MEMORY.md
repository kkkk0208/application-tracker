## 当前实现

### 投递记录与数据

- 弹窗记录投递、岗位信息定向提取、重复提示、表格/看板、状态时间线及 Excel 导入导出保留。
- 未保存的弹窗内容按岗位链接在 `chrome.storage.session` 暂存，支持恢复与清空；不是跨浏览器重启的长期草稿。
- 记录、资料和问答的持久化修改统一通过后台工作线程的串行队列，避免多个页面同时读改整个数组导致丢写。
- 表格与看板监听本地存储变化；改状态只提交状态字段。编辑时只提交实际变化字段，并检查同字段冲突。
- 日期使用本机年月日，覆盖上海时间凌晨仍被 UTC 算为前一天的回归场景。

### 申请助手

- 弹窗“申请信息”打开统一侧栏。会话绑定目标标签和文档，不因切换标签自动换目标。
- 合并可访问的主/子框架，展示覆盖情况。字段定位、文档与结构变化检查用于阻止旧计划写到新控件。
- 按原题、分区、帮助文字、约束和实体理解字段；AI 可复核未知或不确定题意，不只接收未匹配关键词。
- 批量填写前读取网页真实选项，包括受支持的自定义/搜索下拉；读取失败、选项变化或不唯一匹配时留下说明。
- 本地资料先准备，AI 为可选补充。预览按分组展示，支持对应经历调整、定位、筛选、折叠和必填缺口导航。
- `visionEnabled` 单独默认关闭。启用后对当前视口主页面的疑难字段进行截图辅助，遮盖输入控件和内嵌页面，用 V1–V30 标记对应现有字段；只补题目/教育分区，答案仍从本地资料及原有校验流程获得。
- 截图前后核对目标活动标签、文档和布局；页面变化、权限缺失或图片请求失败则回退文字流程。原图及遮盖截图均不写入存储；其他可见内容可能仍含个人信息，不能声称完全匿名。不开启 all_urls/debugger，不运行任意坐标点击。
- “更新预览，保留修改”在文档、资料和记忆仍可对应时保留草稿与明确取消的选择；新的有效答案默认加入预览，统一确认后才填写。
- 逐项写入后回读核验；用户已有内容保留。可停止后续操作，也可尝试撤销助手写入且未被用户再次修改的值。
- 密码、验证码、上传、声明、签名和最终提交由用户操作，不自动翻页或新增网站经历块。

### 资料、记忆与 AI

- 中英文个人资料仍是事实来源。保存后助手直接构建本地事实，不要求“生成 AI 信息库”；旧入口已从个人资料页移除。
- 填写结果不自动晋升为长期记忆。学习和结果保存都先预览，再由用户选择答案和适用范围。
- 记忆具有主体、语言、范围和范围版本。链接范围保留岗位查询参数/路由，移除常见凭据和跟踪参数；旧版缺少可靠范围的答案待重新确认。
- 记忆编辑使用中文主体和范围选项，保留已有自定义主体；同条编辑有冲突检查。
- AI 默认关闭。开启后准备/更新问题时按需调用 OpenAI；题意理解发送题目与类别，答案建议按题目发送相关资料片段和岗位背景。
- API Key 保存在本地设置，用作请求鉴权，不在提示词、完整备份或恢复点中。不能继续声称“插件不联网/不调用云端”。

### 完整备份

- 记忆页提供 schemaVersion 3、format `application-tracker-backup` 的完整 JSON 导出和恢复。
- 包含记录、个人资料、当前问答、旧问答及历史备份；排除 API Key、AI 设置、旧派生 AI 索引、临时草稿和会话。
- 导入先校验并预览，可合并或替换。合并保留同 ID 的当前内容及已有整份个人资料；资料不同的新增问答待确认。
- 恢复前保留本机完整恢复点；预览到确认之间有其他页面写入时要求重新预览。
- 兼容旧 schemaVersion 2 资料备份，不误删当前投递记录。Excel 仍只覆盖投递记录，不能替代完整 JSON。
