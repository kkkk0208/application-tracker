L0062 | ## 当前实现
L0063 | 
L0064 | ### 投递记录与数据
L0065 | 
L0066 | - 弹窗记录投递、岗位信息定向提取、重复提示、表格/看板、状态时间线及 Excel 导入导出保留。
L0067 | - 未保存的弹窗内容按岗位链接在 `chrome.storage.session` 暂存，支持恢复与清空；不是跨浏览器重启的长期草稿。
L0068 | - 记录、资料和问答的持久化修改统一通过后台工作线程的串行队列，避免多个页面同时读改整个数组导致丢写。
L0069 | - 表格与看板监听本地存储变化；改状态只提交状态字段。编辑时只提交实际变化字段，并检查同字段冲突。
L0070 | - 日期使用本机年月日，覆盖上海时间凌晨仍被 UTC 算为前一天的回归场景。
L0071 | 
L0072 | ### 申请助手
L0073 | 
L0074 | - 弹窗“申请信息”打开统一侧栏。会话绑定目标标签和文档，不因切换标签自动换目标。
L0075 | - 合并可访问的主/子框架，展示覆盖情况。字段定位、文档与结构变化检查用于阻止旧计划写到新控件。
L0076 | - 按原题、分区、帮助文字、约束和实体理解字段；AI 可复核未知或不确定题意，不只接收未匹配关键词。
L0077 | - 批量填写前读取网页真实选项，包括受支持的自定义/搜索下拉；读取失败、选项变化或不唯一匹配时留下说明。
L0078 | - 本地资料先准备，AI 为可选补充。预览按分组展示，支持对应经历调整、定位、筛选、折叠和必填缺口导航。
L0079 | - `visionEnabled` 单独默认关闭。启用后对当前视口主页面的疑难字段进行截图辅助，遮盖输入控件和内嵌页面，用 V1–V30 标记对应现有字段；只补题目/教育分区，答案仍从本地资料及原有校验流程获得。
L0080 | - 截图前后核对目标活动标签、文档和布局；页面变化、权限缺失或图片请求失败则回退文字流程。原图及遮盖截图均不写入存储；其他可见内容可能仍含个人信息，不能声称完全匿名。不开启 all_urls/debugger，不运行任意坐标点击。
L0081 | - “更新预览，保留修改”在文档、资料和记忆仍可对应时保留草稿与明确取消的选择；新的有效答案默认加入预览，统一确认后才填写。
L0082 | - 逐项写入后回读核验；用户已有内容保留。可停止后续操作，也可尝试撤销助手写入且未被用户再次修改的值。
L0083 | - 密码、验证码、上传、声明、签名和最终提交由用户操作，不自动翻页或新增网站经历块。

L0086 | 
L0087 | - 中英文个人资料仍是事实来源。保存后助手直接构建本地事实，不要求“生成 AI 信息库”；旧入口已从个人资料页移除。
L0088 | - 填写结果不自动晋升为长期记忆。学习和结果保存都先预览，再由用户选择答案和适用范围。

L0092 | - API Key 保存在本地设置，用作请求鉴权，不在提示词、完整备份或恢复点中。不能继续声称“插件不联网/不调用云端”。
